## Решение

Решение построено на квадрокоптере «Клевер 5 ДЕВ» (Raspberry Pi 5) с тепловизором TR256i и AI-ускорителем Hailo-8L AI HAT+. Вся обработка выполняется бортовым компьютером автономно, без участия оператора в полёте.

### Компоненты и взаимодействие

1. **`hailo_node.py`** — ROS 2-нода детекции загрязнений. Подписывается на топик основной камеры, выполняет инференс YOLO-модели, скомпилированной в формат HEF, на ускорителе Hailo-8L. Включает препроцессинг (letterbox), разбор сырых выходных тензоров (DFL + sigmoid), NMS и публикацию результатов в топик `/hailo/detections`, а также отладочных изображений с рамками. Классы загрязнений: `kl_1`, `kl_2`, `kl_3`.
2. **`inspection_with_position.py`** — главный скрипт полётной миссии. Дрон взлетает, последовательно облетает заданные точки с солнечными панелями, на каждой точке:
   - собирает кадры с тепловизора, усредняет термограмму и ищет холодные области внутри горячих контуров (признак неработающего сегмента панели — разница температур более 3 °C);
   - читает свежие детекции нейросети из файла-моста `/tmp/hailo_data.json`;
   - сигнализирует результатом светодиодным модулем (белый — перелёт, зелёный — норма, жёлтый — загрязнение, красный — тепловая аномалия);
   - записывает фактическую позицию маркера панели.
   
   После возврата и посадки формируется итоговый JSON-отчёт.
3. **`Dream_Team-0-1.json`** — итоговый отчёт миссии: число панелей, для каждой — флаг тепловой аномалии, тип визуального загрязнения (0–3) и координаты маркера.
4. **`drone_api.py`** — HTTP-бэкенд на дроне (порт 8081): отдаёт отчёт (`GET /report`), веб-панель и проксирует запросы к локальной LLM (Ollama) для автоматического анализа отчёта.
5. **`index.html`** — веб-панель оператора: карточки состояния каждой панели и чат с LLM-ассистентом, отвечающим на вопросы на основе данных отчёта (все обращения проходят через дрон, на ноутбуке ничего устанавливать не нужно).
6. **`screenshot.py`** — вспомогательная утилита: скриншоты и видео с основной камеры и тепловизора (JET-цветокарта, оверлей средней/максимальной температуры) — использовалась для отладки и проверки оборудования.

### Ключевые фрагменты кода

**Получение термограммы с TR256i** (нижняя половина кадра — матрица температур uint16, шаг 1/64 K):

```python
def get_thermal_frame(drone):
    msg = drone.get_image_msg("thermal_camera")
    raw = np.frombuffer(msg.data[:msg.height * msg.width * 2],
                        dtype="<u2").reshape(msg.height, msg.width)
    # нижняя половина — температуры, перевод в градусы Цельсия
    return raw[msg.height // 2:, :].astype(np.float32) / 64.0 - 273.15
```
