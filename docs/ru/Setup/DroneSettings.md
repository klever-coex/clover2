# Настройки дрона

Для настройки камер, карты и всего что работает через ROS2 можно использовать встроенную графическую утилиту *clover2-settings*.
Настройки представляются в виде древовидной структуры (как папки на компьютере).

Для навигации используется или мышка или клавиши на клавиатуре:
- стрелочки вверх и вниз для выбора поля настройки
- enter для выбора настройки
- esc для выхода на настройку выше и выхода из программы
- ctrl+s для сохранения изменненых настроек

Утилита устроенна так что не получится установить неверное значение параметра.

## Структура настроек для Клевер 5

```
├── main_camera - Группа настроек относящихся к основной (нижней) камере
│   ├── enable - Включение/Выключение основной камеры
│   └── feature_detector - Включение/Выключение распознования Aruco на основной камере
├── front_camera - Группа настроек относящихся к передней камере
│   └── enable - Включение/Выключение передней камеры
├── optical_flow - Группа настроек относящихся к Optical Flow
│   └── enable - Включение/Выключение Optical Flow
├── localization - Группа настроек относящихся к позиционированию по карте Aruco меток
│   ├── map_server - Группа настроек относящихся к серверу карты
│   │   ├── enable - Включение/Выключение сервера карты Aruco
│   │   └── map_filename - название файла с картой
│   └── aruco_tracker - Группа настроек относящихся к навигации по карте Aruco меток
│       └── enable - Включение/Выключение навигации
└── 2d_lidar - Группа настроек относящихся к 2d лидару
    └── enable - Включение/Выключение лидара
```
