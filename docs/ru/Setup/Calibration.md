# Калибровка датчиков

Для калибровки датчиков перейдите в панель *Vehicle Configuration* и выберите меню *Sensors*.

```{caution}
Перед началом калибровки убедитесь, что конструктор находится на устойчивой поверхности.
```

## Гироскоп

```{figure} ../../assets/common/setup/qgc-cal-gyro.webp
:alt: Калибровка гироскопа в QGroundControl
:width: 90%
:align: center

Калибровка гироскопа
```
<br>

1. Выберите меню *Gyroscope*.
3. Нажмите *OK*.
4. Дождитесь сообщения об успешном завершении калибровки.

```{warning}
Не перемещайте конструктор до завершения калибровки.
```

Дополнительная информация: [PX4 Gyroscope Calibration](https://docs.px4.io/main/en/config/gyroscope.html).

## Акселерометр

```{figure} ../../assets/common/setup/qgc-cal-acc.webp
:alt: Калибровка акселерометра в QGroundControl
:width: 90%
:align: center

Калибровка акселерометра
```
<br>

1. Выберите меню *Accelerometer*.
2. Выберите ориентацию полетного контроллера *ROTATION_NONE*, если контроллер установлен стрелкой в направлении носа конструктора.
3. Последовательно устанавливайте конструктор в положения, указанные QGroundControl.
4. После появления желтой рамки удерживайте конструктор в заданном положении.
5. Не перемещайте конструктор до появления зеленой рамки.
6. Повторите процедуру для всех положений, предложенных программой.

Дополнительная информация: [PX4 Accelerometer Calibration](https://docs.px4.io/main/en/config/accelerometer.html).

## Уровень горизонта

```{figure} ../../assets/common/setup/qgc-cal-level.webp
:alt: Калибровка горизонта в QGroundControl
:width: 90%
:align: center

Калибровка уровня горизонта
```
<br>

1. Выберите меню *Level Horizon*.
2. Выберите ориентацию полетного контроллера *ROTATION_NONE*, если контроллер установлен стрелкой в направлении носа конструктора.
4. Нажмите *OK*.
5. Не перемещайте конструктор до завершения калибровки.
6. Дождитесь сообщения об успешном завершении калибровки.

Дополнительная информация: [PX4 Level Horizon Calibration](https://docs.px4.io/main/en/config/level_horizon_calibration.html).
