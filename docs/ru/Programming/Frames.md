# Системы координат

Cистема координат — математический способ задавать координаты: начало координат + оси + ориентация осей.

Frame (фрейм) — именованная система координат, привязанная к объекту или пространству, положение которой можно выразить относительно другой frame.

```{note}
Для работы с фреймами в Клевере используется ROS-пакет [tf2](https://index.ros.org/p/tf2/).
```

Основные фреймы пакета `clover2` организованы в соответствии с соглашением [REP 105](https://reps.openrobotics.org/rep-0105/):

* `base_link` — координаты относительно дрона;
* `odom` — координаты относительно точки инициализации полетного контроллера;
* `map` – координаты относительно [карты маркеров](./ArucoMap) (в конфигурации карты можно изменить название этого фрейма, но рекомендуется использовать стандартное название для соответствия с соглашением).

Помимо указанны выше фреймов, для каждого маркера в карте создается отдельный фрейм. По умолчанию, фреймы маркеров называются `map_aruco_<id>`, где `<id>` — идентификатор маркера.

```{hint}
Точка пересечения цветных осей — начало соответствующего фрейма. Стрелки показывают положительные направления осей: X — красная, Y — зелёная, Z — синяя.

Согласно [REP 103](https://reps.openrobotics.org/rep-0103/), для фреймов, связанных с корпусом дрона, ось X направлена вперёд, Y — влево, Z — вверх. 
```
