# LED-лента

LED-лента позволяет управлять светодиодами на квадрокоптере с помощью Python. 

## Инициализация

```python
from clover2 import Clover2

drone = Clover2()
# или с именем ноды:
drone = Clover2("my_drone")
```

`Clover2` — обертка над ROS 2 Node. При создании объекта Clover2 создается нода и запускается фоновый поток для работы ROS 2.

## Анимации

Самый простой способ управлять лентой — использовать встроенные анимации. Каждая анимация принимает параметр `duration`, который задает длительность анимации в секундах.
Если `duration` не указан, анимация будет работать до тех пор, пока вы не запустите другую анимацию или не отправите прямую команду управления лентой.

```python
drone.rainbow(period=2.0, duration=5.0)     # радуга, полный цикл за 2 с, 5 секунд
drone.blink(255, 0, 0, period=0.5)          # красное мигание, период 0.5 с
drone.solid_color(0, 255, 0, duration=1.0)  # зеленая заливка на 1 секунду
drone.clear()                               # выключение всех светодиодов
```

Параметры анимаций:

| Метод                                          | Аргументы                                                 |
| ---------------------------------------------- | --------------------------------------------------------- |
| `rainbow(period, brightness, duration)`        | `period` — время полного цикла радуги (по умолчанию 2.0)  |
| `blink(r, g, b, period, brightness, duration)` | `period` — период полного цикла включения /выключения (по умолчанию 1.0) |
| `solid_color(r, g, b, brightness, duration)`   | заливка всей ленты одним цветом                           |
| `clear()`                                      | выключение всех светодиодов                               |

## Прямое управление

С помощью прямого управления вы можете задать один цвет для всей ленты.

```python
# Заливка всей ленты
drone.fill(255, 255, 0)  # желтый
```

:::{attention}
При попиксельном управлении количество элементов в массиве должно совпадать с количеством светодиодов в ленте.
:::

```python
count = drone.led_count     # колличетсво светодиодов в ленте
leds = [(0, 0, 0)] * count  # выключает ленту
leds[4] = (0, 255, 0)       # делает 5-й светодиод зеленым

# Попиксельное управление - [(r, g, b), ...]
drone.send_frame(leds, brightness=0.5)
```

## Пример: демонстрация эффектов

```python
import time
from clover2 import Clover2

drone = Clover2()

drone.rainbow(period=2.0, duration=5.0)
time.sleep(5.5)

drone.blink(255, 255, 255, period=0.5, duration=5.0)
time.sleep(5.5)

for r, g, b in [(255, 0, 0), (0, 255, 0), (0, 0, 255)]:
    drone.solid_color(r, g, b, duration=1.0)
    time.sleep(1.2)

drone.clear()
```
