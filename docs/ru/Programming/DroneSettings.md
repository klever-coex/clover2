# Настройки квадрокоптера

Для настройки камер, карты и других компонентов, работающих через ROS 2, используйте встроенную графическую утилиту ***clover2-settings***.
Утилита отображает настройки в виде древовидной структуры, похожей на структуру папок на компьютере.

Для навигации по меню используйте мышь или клавиши клавиатуры:

- стрелки `вверх` и `вниз` — для навигации
- `Enter` — для выбора параметра
- `Esc` — для возврата на уровень выше или выхода из программы
- `Ctrl+s` — для сохранения изменненых настроек

Утилита проверяет значения параметров и не позволяет установить недопустимое значение.

## Структура настроек для Клевер 5

```text
├── main_camera — Настройки основной (нижней) камеры
│   ├── enable — Включение/Выключение основной камеры
│   └── feature_detector — Включение/Выключение распознования Aruco на основной камере
├── front_camera — Настройки передней камеры
│   └── enable — Включение/Выключение передней камеры
├── optical_flow — Настройки Optical Flow
│   └── enable — Включение/Выключение Optical Flow
├── localization — Настройки позиционирования по карте ArUco-меток
│   ├── map_server — Настройки сервера карты
│   │   ├── enable — Включение/Выключение сервера карты Aruco
│   │   └── map_filename — Имя файла с картой
│   └── aruco_tracker — Настройки навигации по карте Aruco-меток
│       └── enable — Включение/Выключение навигации
└── 2d_lidar — Настройки 2D-лидара
    └── enable — Включение/Выключение лидара
```

```{warning}
После изменения настроек перезапустите сервис clover2 командой: 
```

```bash
sudo systemctl restart clover2
```

## Пример: Настройка файла карты

Для запуска графического интерфейса выполните в терминале команду:

```bash
clover2-settings
```

После выполненя команды откроется TUI(Terminal User Interface) — текстовый интерфейс пользователя в терминале.

```{figure} @assets@/common/setup/drone-settings/main-screen.webp
:alt: Экран настроек
:width: 90%
:align: center
```

<br>

С помощью стрелок `верх` и `вниз` выберите `localization` и нажимем `Enter`, чтобы открыть группу настроек.

```{figure} @assets@/common/setup/drone-settings/localization-menu.webp
:alt: Экран настроек localization
:width: 90%
:align: center
```

<br>

Аналогично выберите `map_server`. Эта группа содержит настройки сервера карты. Затем выберите  `map_filename`.

```{figure} @assets@/common/setup/drone-settings/map-server-menu.webp
:alt: Экран настроек map_server
:width: 90%
:align: center
```

<br>

Откроется редактор значения параметра. 
Для перемещения курсора используйте стрелки `влево` и `вправо`. 
После завершения редактирования нажмите `Tab`. C помощью стрелок `вверх` и `вниз` выберите кнопку `Save` для сохранения значения или `Cancel` для отмены изменений. 

```{figure} @assets@/common/setup/drone-settings/map-filename-edit.webp
:alt: Экран настроек map_server
:width: 90%
:align: center
```

<br>

Чтобы сохранить измененные настройки в файл, нажмите сочетание клавиш `Ctrl+S`. Появится уведомление о сохранении.

```{figure} @assets@/common/setup/drone-settings/saved-example.webp
:alt: Сохранение настроек
:width: 90%
:align: center
```

<br>

Несколько раз нажмите `Esc`, чтобы выйти из программы.
Затем перезапустите сервис clover2 командой:

```bash
sudo systemctl restart clover2
```
