# Настройки дрона

Для настройки камер, карты и всего что работает через ROS2 можно использовать встроенную графическую утилиту ***clover2-settings***.
Настройки представляются в виде древовидной структуры (как папки на компьютере).

Для навигации используется или мышка или клавиши на клавиатуре:

- стрелочки вверх и вниз для выбора поля настройки
- enter для выбора настройки
- esc для выхода на настройку выше и выхода из программы
- ctrl+s для сохранения изменненых настроек

Утилита устроенна так что не получится установить неверное значение параметра.

## Структура настроек для Клевер 5

```text
├── main_camera — Группа настроек относящихся к основной (нижней) камере
│   ├── enable — Включение/Выключение основной камеры
│   └── feature_detector — Включение/Выключение распознования Aruco на основной камере
├── front_camera — Группа настроек относящихся к передней камере
│   └── enable — Включение/Выключение передней камеры
├── optical_flow — Группа настроек относящихся к Optical Flow
│   └── enable — Включение/Выключение Optical Flow
├── localization — Группа настроек относящихся к позиционированию по карте Aruco меток
│   ├── map_server — Группа настроек относящихся к серверу карты
│   │   ├── enable — Включение/Выключение сервера карты Aruco
│   │   └── map_filename — название файла с картой
│   └── aruco_tracker — Группа настроек относящихся к навигации по карте Aruco меток
│       └── enable — Включение/Выключение навигации
└── 2d_lidar — Группа настроек относящихся к 2d лидару
    └── enable — Включение/Выключение лидара
```

```{warning}
Для измененных настроек необходмо перезапустить сервис clvoer2. Команда приложенна ниже
```

## Пример: Настройка файла карты

Для запуска графического интерфейса вы полните команду в терминале:

```bash
clover2-settings
```

После выполненя команды откроется TUI(Terminal User Interface).

```{figure} @assets@/common/setup/drone-settings/main-screen.webp
:alt: Экран настроек
:width: 90%
:align: center
```

<br>

С помощью стрелок верх и вниз переводите курсор на `localization` и нажимем enter, это откроет вкладу.

```{figure} @assets@/common/setup/drone-settings/localization-menu.webp
:alt: Экран настроек localization
:width: 90%
:align: center
```

<br>

Аналогично выбираем `map_server`, эта группа настроек относится к серверу карты. Выбираем `map_filename`.

```{figure} @assets@/common/setup/drone-settings/map-server-menu.webp
:alt: Экран настроек map_server
:width: 90%
:align: center
```

<br>

Открывается редактор значения. Для перемещения курсора используйте стрелочки влево и вправо. После завершения редактирования нажмите tab и стрелочками вверх и вниз выберите кнопку `Save` или `Cancel`.

```{figure} @assets@/common/setup/drone-settings/map-filename-edit.webp
:alt: Экран настроек map_server
:width: 90%
:align: center
```

<br>

Для сохранения изменений в файл нажмите сочетание клавиш ctrl+S. Появится уведомление о сохранении.

```{figure} @assets@/common/setup/drone-settings/saved-example.webp
:alt: Сохранение настроек
:width: 90%
:align: center
```

<br>

Далее надо несколько раз нажать esc чтоб выйти из приложения. И выполнить команду перезапуска сервиса clover2:

```bash
sudo systemctl restart clover2
```
