«Клевер» — учебный конструктор программируемого квадрокоптера, разработанный с учетом отраслевых стандартов. В комплект входит все необходимое для сборки, настройки и эксплуатации конструктора.

Конструктор квадрокоптера сочетает современные аппаратные компоненты и актуальный программный стек. В его основе — производительный полетный контроллер на базе STM32H7 с PX4, обеспечивающий высокую производительность вычислений и стабильную работу алгоритмов управления. Raspberry Pi 5 используется в качестве бортового компьютера для запуска узлов ROS 2, алгоритмов компьютерного зрения и пользовательских программ.

Обновленный «Клевер» ориентирован на современную робототехническую экосистему:

- **ROS 2** — для построения масштабируемых, распределенных и надежных систем управления.
- **Docker** — для изоляции программных окружений, воспроизводимой сборки и удобного развертывания.
- **Готовые контейнеры и шаблоны проектов** — для быстрого начала работы.
- **Открытый исходный код** — для обучения и кастомизации.

Такой подход позволяет использовать конструктор квадрокоптера на разных уровнях подготовки. Преднастроенный образ для Raspberry Pi, готовые примеры и подробная документация позволяют начинающим пользователям быстро запустить первый полет и начать программировать без сложной настройки. Опытные разработчики могут использовать конструктор как основу для более сложных проектов, включая автономную навигацию, задачи компьютерного зрения, разработку роевых систем, а также исследовательские и прикладные решения.

В комплект входит полностью настроенный образ для Raspberry Pi со всем необходимым программным обеспечением, библиотеками и инструментами разработки. Исходный код и документация доступны на [GitHub](https://github.com/klever-coex/clover2).
