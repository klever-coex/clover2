# `settings_server`

`settings_server` — плагин пакета `clover2_ui/clover2_http_plugins`, который предоставляет REST API для просмотра и изменения настроек запуска проекта `clover2`. Плагин использует класс `clover2_ui::api::settings::config_field` для работы с конфигурацией. На этом же классе основан TUI-редактор настроек, который запускается командой `clover2_ui settings`.

Конфигурация состоит из двух частей:
*	**YAML-схема** описывает структуру настроек: названия и типы полей, значения по умолчанию, описания и допустимые значения.
*	**YAML-файл значений** содержит пользовательские значения, которые переопределяют значения по умолчанию из схемы.

## Маршруты

Плагин предоставляет следующие HTTP-маршруты:

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/api/settings/schema` | Получить YAML-схему настроек с текущими значениями полей (`value` -> иначе `default`) |
| PUT | `/api/settings/values` | Передать полный набор значений настроек для сохранения |

## Параметры

Плагин использует следующие параметры:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `settings_server.schema_path` | *(пусто)* | Путь к YAML-файлу схемы настроек, например `klever5.yaml` из пакета `clover2_bringup`. Если путь не указан, плагин отключен |
| `settings_server.values_path` | *(пусто)* | Путь к YAML-файлу значений. Используется тот же файл конфигурации, который передается лаунчеру и применяется в TUI-редакторе |

## Чтение схемы

Чтобы получить структуру настроек и их текущие значения, отправьте GET-запрос: `GET /api/settings/schema`.
Сервер возвращает JSON-объект со схемой настроек.
Каждое поле схемы может содержать следующие параметры:
*	`name` — имя поля;
*	`type` — тип данных;
*	`description` — описание настройки;
* `default` — значение по умолчанию;
* `enum` — список допустимых значений;
* `children` — вложенные поля для объектов типа object;
* `value` — текущее значение поля, если оно задано в файле значений.

Пример ответа:

```json
{"valid": true, "root": {"children": [{"name": "fcu_bridge", "type": "object",
  "description": "Flight controller unit bridge", "children": [
    {"name": "fcu_conn", "type": "str", "description": "FCU connection type",
     "default": "uart", "enum": ["usb", "uart", "tcp", "udp"], "value": "tcp"}]}]}}
```

## Сохранение значений

Для изменения настроек отправьте PUT-запрос: `PUT /api/settings/values`. В теле запроса передайте JSON-объект `values` с полным деревом текущих значений. Формат данных соответствует структуре конфигурации, которую использует TUI-редактор.

Пример запроса:

```json
{"values": {"fcu_bridge": {"fcu_conn": "tcp"}, "main_camera": {"enable": true}}}
```

Если запрос содержит неизвестный ключ, значение неподходящего типа или значение, отсутствующее в списке `enum`, сервер возвращает HTTP-код `400` (Bad Request).

Capability плагина — `settings`. Она включается в манифест (`GET /api/manifest`) только после успешной загрузки YAML-схемы. Если схема не загружена, маршруты плагина возвращают HTTP-код `503` (Service Unavailable).
