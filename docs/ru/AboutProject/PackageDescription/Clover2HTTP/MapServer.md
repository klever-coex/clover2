# `map_server`

`map_server` — плагин пакета `clover2_ui/clover2_http_plugins`, который предоставляет REST CRUD маркеров ArUco-карты. С его помощью можно получить данные карты, добавить новый маркер, изменить его параметры или удалить маркер. 

Для изменения карты плагин обращается к сервису `clover2_pose_msgs/srv/ModifyMap` ноды карты. Плагин не хранит собственную копию состояния карты: для чтения данных он использует кэшированный снимок, полученный клиентом от ноды карты.

## Маршруты

Плагин предоставляет следующие HTTP-маршруты:

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/api/map` | Получить полную карту: метаданные (имя, фрейм, словарь) и список всех маркеров |
| GET | `/api/map/marker/-/{id}` | Получить маркер по его `id` |
| POST | `/api/map/marker` | Добавить новый маркер |
| PUT | `/api/map/marker/-/{id}` | Изменить параметры маркера (`id` в пути и `id` в теле запроса должны совпадать) |
| DELETE | `/api/map/marker/-/{id}` | Удалить маркер по его `id` |

## Параметры

Плагин использует следующий параметр:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `map_server.map_node` | `map_server` | Имя ноды карты, к которой подключается клиент плагина |

## Изменение карты

Для добавления и изменения маркера передайте в теле HTTP-запроса объект `marker_info`.
Объект содержит следующие поля:
*	`id` — идентификатор маркера;
*	`type` — тип маркера;
*	`size` — размер маркера;
*	`marker_frame_id` — идентификатор фрейма маркера;
*	`pose` — положение и ориентация маркера.
  
В ответ на запрос сервер возвращает объект `modify_result`:

```json
{"success": true, "error_message": ""}
```

Поле `success` показывает, выполнена ли операция успешно. Если операция завершилась ошибкой, поле `error_message` содержит описание ошибки.

Перед отправкой запроса на ноду карты плагин проверяет корректность данных. Запрос отклоняется с HTTP-кодом `400`, если идентификатор отрицательный, размер не является положительным числом или указан неизвестный тип маркера.

## Capability и доступность

Capability плагина — `map`. Плагин включает эту возможность в манифест (`GET /api/manifest`) только после успешного подключения клиента к ноде карты.
Если нода карты недоступна, плагин периодически пытается восстановить подключение.

* Если сервис ноды карты возвращает ошибку, HTTP-сервер возвращает `modify_result{false}`.
* Если сервис не отвечает в течение 5 секунд, сервер возвращает HTTP-код `504` (Gateway Timeout).
