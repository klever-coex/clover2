## Сборка рамы

1. Совместите 4 луча между средней и нижней декой.

    ```{figure} @assets@/ru/assembly/clover5/frame/frame_step_1.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

2. Установите винты M3x12 ([Ячейка 7](#clover5-cell7)) и M3x40 ([Ячейка 6](#clover5-cell6)) со стороны нижней деки, M3x12 ([Ячейка 7](#clover5-cell7)) в крайние отверстия лучей, M3x40 ([Ячейка 6](#clover5-cell6)) в центральные отверстия нижней деки.

    ```{figure} @assets@/ru/assembly/clover5/frame/frame_step_2.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

3. На средней деке установите запрессовочные гайки М3 ([Ячейка 1](#clover5-cell1)) и зафиксируйте их винтами.

    ```{figure} @assets@/ru/assembly/clover5/frame/frame_step_3.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

## Установка моторов

1. Установите моторы в соответствующие отверстия в луче с помощью **винтов М3х8** ([Ячейка 8](#clover5-cell8)).

    ```{figure} @assets@/ru/assembly/clover5/motor.webp
    :alt: Установка моторов
    :width: 700px
    :align: center
    ```

```{caution}
Убедитесь, что моторы закреплены с помощью винтов М3х8, в противном случае может возникнуть короткое замыкание между обмотками.
```

## Установка ESC

1. Установите регулятор оборотов (ESC) поверх винтов M3x40 ([Ячейка 6](#clover5-cell6)) на средней деке. Разъем питания аккумулятора должен быть направлен назад.

    ```{figure} @assets@/ru/assembly/clover5/esc_step_1.webp
    :alt: Установка ESC
    :width: 700px
    :align: center
    ```

2. Подсоедините к моторам разъемы MR30 от регулятора оборотов (ESC), уложите провода так, как показано на рисунке, после чего закрепите их на лучах с помощью пластиковых хомутов.

    ```{figure} @assets@/ru/assembly/clover5/esc_step_2.webp
    :alt: Установка ESC
    :width: 700px
    :align: center
    ```

## Установка Raspberry Pi

1. Установите на монтажную деку из поликарбоната стойки M2.5 ([Ячейка 3](#clover5-cell3)) с помощью винтов M2.5x4 ([Ячейка 17](#clover5-cell17)).

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_1.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

2. Закрутите винты. Используйте биту H1.5/HEX1.5.

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_2.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

3. Установите Raspberry pi 5 поверх стоек M2.5.

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_3.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

4. Зафиксируйте плату Raspberry Pi 5 с помощью винтов М2.5х4 ([Ячейка 17](#clover5-cell17)).

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_4.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

5. Снимите пленки с термопрокладок и установите их на выделенные позиции на изображении. Установите радиатор охлаждения на Raspberry pi, для этого вставьте фиксирующие клипсы через радиатор в Raspberry pi. Подключите систему охлаждения в порт отмеченный на изображении.

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_5.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

6. Raspberry Pi с радиатором в сборе.

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_6.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

7. Установите нейлоновые стойки 30мм ([Ячейка 21](#clover5-cell21)) на деку с Raspberry pi с помощью винтов M3x8 ([Ячейка 8](#clover5-cell8)).

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_7.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

8. Вид с установленными нейлоновыми стойками.

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_8.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

9. Установите собранную деку c Raspberry pi на нижнюю часть квадрокоптера в демпферные стойки, зафиксируйте на винты M3x4 ([Ячейка 10](#clover5-cell10)).

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_9.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

10. Подключите к Raspberry шлейф передачи данных. Подключение производится во внешнюю линию гребенки, начиная с 4 порта относительно порта SD карты(черный провод в 14 порту, см. pinout). Подключение ответной части производится в порт UART 4 на полетном контроллере(черный провод распологается в крайнем правом углу).
    
    ```{figure} @assets@/ru/assembly/clover5/RPI_step_10.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

    ```{figure} @assets@/ru/assembly/clover5/RPI_pinout.webp
    :alt: Установка Raspberry Pi
    :width: 400px
    :align: center
    ```

21. Установите кожух поверх алюминиевых стоек и закрепите приемник на пластиковый хомут, в выделенные отверстия на изображении. Уложите провода в вырез для проводов. Подключите экран к Raspberry pi, красный провод подключается в левый крайний пин внутренней части гребенки, относительно SD карты(красный - 1 пин, чёрный - 9 пин). 

    ```{figure} @assets@/ru/assembly/clover5/RPI_step_21.webp
    :alt: Установка Raspberry Pi

    :align: center
    ```

## Установка защиты, ножек и LED ленты

1. Проденьте ремешок в верхнюю деку, после чего закрепите ее на винты M3x8 ([Ячейка 8](#clover5-cell8)) в алюминиевые стойки, закрепите разъем питания с помощью винтов M2.5x6 ([Ячейка 18](#clover5-cell18)). Бита для сборки деки - H2.0/HEX2.0, для разъема - H1.5/HEX1.5.

    ```{figure} @assets@/ru/assembly/clover5/other_step_1.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

2. Расположите снизу в виде квадрата перемычки защиты, после чего на углы выложите нижние дуги защиты, зафиксируйте на винты M3x10 ([Ячейка 13](#clover5-cell13)) сверху, снизу нейлоновые стойки 40мм ([Ячейка 23](#clover5-cell23)).

    ```{figure} @assets@/ru/assembly/clover5/other_step_2.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

3. Зафиксируйте винтами M3x8 ([Ячейка 8](#clover5-cell8)) верхние дуги и перемычки в обратном порядке, должно получится так, что перемычки направлены внутрь, а дуги наружу.

    ```{figure} @assets@/ru/assembly/clover5/other_step_3.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

4. Установите и зафиксируйте запрессовочные гайки М3 ([Ячейка 1](#clover5-cell1)) в отверстия по краям лучей.

    ```{figure} @assets@/ru/assembly/clover5/other_step_4.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

5. Установите с нижней стороны защиту и зафиксируйте её на винты M3x10 ([Ячейка 13](#clover5-cell13)).

    ```{figure} @assets@/ru/assembly/clover5/other_step_5.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

6. С одной стороны маленькой ножки вкрутите винты M3x6 ([Ячейка 9](#clover5-cell9)) во все отверстия, с другой стороны зафиксируйте их на алюминиевыми стойками 10мм ([Ячейка 14](#clover5-cell14)). В нижнем отверстии поверх стойки наденьте ножку из TPU ([Ячейка 25](#clover5-cell25)).

    ```{figure} @assets@/ru/assembly/clover5/other_step_6.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

7. Разместите маленькую ножку на луче, как показано на изображении и зафиксируйте винтами M3x6 ([Ячейка 9](#clover5-cell9)). Выполните тоже самое для остальных ножек.

    ```{figure} @assets@/ru/assembly/clover5/other_step_7.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

8. Наклейте LED ленту на окружность (Пластиковое кольцо для крепежа LED ленты) после чего установите в крючки на ножках и зафиксируйте провода пластиковым хомутом. Подключите питание во второй свободный UBEC, а сигнальный провод подключите в 9 GPIO (21 пин).

    ```{figure} @assets@/ru/assembly/clover5/other_step_8.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

9. Установите пропеллеры в соответствии с классическим вращением, как представлено на изображении.

    ```{figure} @assets@/ru/assembly/clover5/other_step_9.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

```{caution}
Проверьте, что ни один из компонентов не остался незакрепленным. Перед первым включением убедитесь, что пропеллеры не задевают кожух и провода.
```
