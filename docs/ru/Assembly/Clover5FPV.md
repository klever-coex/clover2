## Сборка рамы

1. Совместите 4 луча между средней и нижней декой, между ними установите проставку.

    ```{figure} @assets@/ru/assembly/clover5-fpv/frame/frame_step_1.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

2. Установите винты M3x12 ([Ячейка 7](#clover5-fpv-cell7)) и M3x40 ([Ячейка 6](#clover5-fpv-cell6)) со стороны нижней деки, M3x12 ([Ячейка 7](#clover5-fpv-cell7)) в крайние отверстия лучей, M3x40 ([Ячейка 6](#clover5-fpv-cell6)) в центральные отверстия нижней деки.

    ```{figure} @assets@/ru/assembly/clover5-fpv/frame/frame_step_2.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

3. На средней деке установите запрессовочные гайки М3 ([Ячейка 1](#clover5-fpv-cell1)) и зафиксируйте их винтами.

    ```{figure} @assets@/ru/assembly/clover5-fpv/frame/frame_step_3.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

## Установка моторов

1. Установите накладки на лучи, так, как показано на изображении.

    ```{figure} @assets@/ru/assembly/clover5-fpv/arm_guard_step_4.webp
    :alt: Установка моторов
    :width: 700px
    :align: center
    ```

2. Установите моторы в соответствующие отверстия в луче с помощью **винтов М3х10** ([Ячейка 13](#clover5-fpv-cell13)).

    ```{figure} @assets@/ru/assembly/clover5-fpv/motor_step_5.webp
    :alt: Установка моторов
    :width: 700px
    :align: center
    ```

```{caution}
Убедитесь, что моторы закреплены с помощью винтов М3х10, в противном случае может возникнуть короткое замыкание между обмотками.
```

## Установка ESC
1. Установите регулятор оборотов (ESC) поверх винтов M3x40 ([Ячейка 6](#clover5-fpv-cell6)) на средней деке. Контакты питания аккумулятора должны быть направлены назад.

    ```{figure} @assets@/ru/assembly/clover5-fpv/esc_step_6.webp
    :alt: Установка ESC
    :width: 700px
    :align: center
    ```

2. Приклейте защитные кожухи и проденьте в них провода моторов. Припаяйте силовые провода и конденсатор на контакты питания ESC, также припаяйте моторы на контакты моторов (см. изобр. ниже).

    ```{figure} @assets@/ru/assembly/clover5-fpv/esc_step_7.webp
    :alt: Установка ESC
    :width: 700px
    :align: center
    ```

3. Наденьте на силовые провода защитный кожух, после чего припаяйте разъём питания XT60. Защелкните защитный кожух на разъёме питания.

    ```{figure} @assets@/ru/assembly/clover5-fpv/xt60_step_8.webp
    :alt: Установка ESC
    :width: 700px
    :align: center
    ```

## Установка полетного контроллера

1. Установите полётный контроллер стрелкой вперед, после чего установите нейлоновые гайки M3 ([Ячейка 2](#clover5-fpv-cell2)) для фиксации полетного контроллера.

    ```{figure} @assets@/ru/assembly/clover5-fpv/fcu_step_9.webp
    :alt: Установка полетного контроллера
    :width: 700px
    :align: center
    ```

2. Установите 6-пиновый шлейф между полетным контроллером и регулятором оборотов (ESC).

    ```{figure} @assets@/ru/assembly/clover5-fpv/fcu_to_esc_step_10.webp
    :alt: Установка полетного контроллера
    :width: 700px
    :align: center
    ```

## Установка видеопередатчика

1. Установите винты M3x10 ([Ячейка 13](#clover5-fpv-cell13)) c нижней стороны деки, с верхней стороны установите видеопередатчик (VTX) и зафиксируйте нейлоновыми гайками M3 ([Ячейка 2](#clover5-fpv-cell2)).

    ```{figure} @assets@/ru/assembly/clover5-fpv/vtx_step_11.webp
    :alt: Установка видеопередатчика
    :width: 700px
    :align: center
    ```

2. Вид с установленным видеопередатчиком (VTX).

    ```{figure} @assets@/ru/assembly/clover5-fpv/vtx_step_12.webp
    :alt: Установка видеопередатчика
    :width: 700px
    :align: center
    ```

## Сборка квадрокоптера

1. Установите алюминиевые стойки M3х30 ([Ячейка 15](#clover5-fpv-cell15)) сверху, снизу зафиксируйте винтами M3x6 ([Ячейка 9](#clover5-fpv-cell9)).

    ```{figure} @assets@/ru/assembly/clover5-fpv/aluminium_30_step_13.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

2. Вид с установленными алюминиевыми стойками.

    ```{figure} @assets@/ru/assembly/clover5-fpv/aluminium_30_step_14.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

3. Установите маунт камеры на передние стойки, так, как показано на изображении снизу.

    ```{figure} @assets@/ru/assembly/clover5-fpv/camera_mount_step_15.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

4. Установите видеокамеру в маунт на винты М2х3 ([Ячейка 20](#clover5-fpv-cell20)) и зафиксируйте в удобном для вас наклоне камеры.

    ```{figure} @assets@/ru/assembly/clover5-fpv/camera_step_16.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

5. Подключите шлейф камеры в разъём для курсовой камеры в полетном контроллере, так, как показано на изображении.

    ```{figure} @assets@/ru/assembly/clover5-fpv/camera_step_17.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

6. Установите в маунт для антенны разъём и затяните ключом для пропеллеров (ключ на 8), после чего подключите разъём антенны в видеопередатчик и установите на задние стойки.

    ```{figure} @assets@/ru/assembly/clover5-fpv/backward_mount_step_18.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

7. Установите радиоприемник ELRS и подключите при помощи шлейфа в порт SBUS/CRSF на полётном контроллере.

    ```{figure} @assets@/ru/assembly/clover5-fpv/elrs_rx_step_19.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

8. Установите защитные накладки сзади, для этого заведите крючок за стойку около полётного контроллера и защёлкните клипсу на задней стойке.
    
    ```{figure} @assets@/ru/assembly/clover5-fpv/backward_guard_step_20.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

9. Установите LED модули, для этого приклейте их на двухсторонний скотч на внутренние стороны лучей (см. изобр. ниже).

    ```{figure} @assets@/ru/assembly/clover5-fpv/led_step_21.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

10. Подключите LED модули в хаб, как показано на изображении. Подключите хаб в разъём LED/Buzzer на полётном контроллере.

    ```{figure} @assets@/ru/assembly/clover5-fpv/led_hub_step_22.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

11. Уложите провода от LED модулей, как показано на изображении.

    ```{figure} @assets@/ru/assembly/clover5-fpv/led_hub_step_23.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

12. Протяните стропу для аккумулятора в посадочные пазы, установите верхнюю деку используя винты М3х6 ([Ячейка 9](#clover5-fpv-cell9)).

    ```{figure} @assets@/ru/assembly/clover5-fpv/top_plate_step_24.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

13. Установите боковую защиту на центральные стойки, защёлкните на клипсы защиты.

    ```{figure} @assets@/ru/assembly/clover5-fpv/side_guard_step_25.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

14. Накрутите антенну видеосвязи на разъём сзади.

    ```{figure} @assets@/ru/assembly/clover5-fpv/vtx_antenna_step_26.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

15. Установите пропеллеры в соответствии с обратным вращением, как представлено на изображении.

    ```{figure} @assets@/ru/assembly/clover5-fpv/props_step_27.webp
    :alt: Сборка квадрокоптера
    :width: 700px
    :align: center
    ```

```{caution}
Проверьте, что ни один из компонентов не остался незакрепленным. Перед первым включением убедитесь, что пропеллеры не задевают кожух и провода.
```
