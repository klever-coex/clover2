## Сборка рамы

1. Совместите 4 луча между средней и нижней декой.

    ```{figure} @assets@/ru/assembly/clover5-dev/frame/frame_step_1.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

2. Установите винты M3x12 ([Ячейка 7](#clover5-dev-cell7)) и M3x40 ([Ячейка 6](#clover5-dev-cell6)) со стороны нижней деки: M3x12 ([Ячейка 7](#clover5-dev-cell7)) в крайние отверстия лучей, M3x40 ([Ячейка 6](#clover5-dev-cell6)) в центральные отверстия нижней деки.

    ```{figure} @assets@/ru/assembly/clover5-dev/frame/frame_step_2.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

3. На средней деке установите запрессовочные гайки М3 ([Ячейка 1](#clover5-dev-cell1)) и зафиксируйте их винтами.

    ```{figure} @assets@/ru/assembly/clover5-dev/frame/frame_step_3.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    ```

## Установка моторов и ESC

1. Установите моторы в соответствующие отверстия в луче с помощью **винтов М3х8** ([Ячейка 8](#clover5-dev-cell8)).

    ```{figure} @assets@/ru/assembly/clover5-dev/motor_step_4.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    ```

    ```{caution}
    Убедитесь, что моторы закреплены с помощью винтов М3х8, в противном случае может возникнуть короткое замыкание между обмотками.
    ```

2. Установите защитные кожухи проводов моторов на лучи.

    ```{figure} @assets@/ru/assembly/clover5-dev/motor_step_5.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    ```

3. С верхней стороны контактов регулятора оборотов припаяйте силовые провода с конденсатором, на провода наденьте защитный колпачок и припаяйте разъём XT60. С нижней стороны контактов регулятора оборотов припаяйте разъём XT30.

    ```{figure} @assets@/ru/assembly/clover5-dev/esc_step_6.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    ```

4. Вид регулятора оборотов (ESC) с припаянным конденсатором и разъёмами.

    ```{figure} @assets@/ru/assembly/clover5-dev/esc_step_7.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    ```

5. Установите регулятор оборотов (ESC) разъемом назад и припаяйте моторы так, как показано на изображении ниже.

    ```{figure} @assets@/ru/assembly/clover5-dev/motor_step_8.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    ```

## Установка Raspberry Pi

1. Установите на монтажную деку из поликарбоната стойки M2.5 ([Ячейка 3](#clover5-dev-cell3)) с помощью винтов M2.5x4 ([Ячейка 17](#clover5-dev-cell17)).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_14.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

2. Закрутите винты. Используйте биту H1.5/HEX1.5.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_15.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

3. Установите Raspberry Pi 5 поверх стоек M2.5 и зафиксируйте плату Raspberry Pi 5 с помощью винтов М2.5х4 ([Ячейка 17](#clover5-dev-cell17)).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_16.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

4. Вид с установленной Raspberry Pi 5.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_17.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

5. Снимите пленки с термопрокладок и установите их на выделенные позиции на изображении. Установите радиатор охлаждения на Raspberry Pi, для этого вставьте фиксирующие клипсы через радиатор в Raspberry Pi. Подключите систему охлаждения в порт, отмеченный на изображении.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_18.webp
    :width: 700px
    :align: center
    ```

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_19.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    ```

Подключите экран к Raspberry Pi: красный провод подключается в левый крайний пин внутренней части гребенки относительно SD карты (красный — 1 пин, чёрный — 9 пин).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_35.webp

    ```

## Установка защиты, ножек и LED ленты

1. Проденьте ремешок в верхнюю деку, после чего закрепите ее на винты M3x8 ([Ячейка 8](#clover5-dev-cell8)) в алюминиевые стойки, закрепите разъем питания с помощью винтов M2.5x6 ([Ячейка 18](#clover5-dev-cell18)). Бита для сборки деки — H2.0/HEX2.0, для разъема — H1.5/HEX1.5.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_36.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

2. Расположите снизу в виде квадрата перемычки защиты, после чего на углы выложите нижние дуги защиты, зафиксируйте на винты M3x10 ([Ячейка 13](#clover5-dev-cell13)) сверху, снизу нейлоновые стойки 40мм ([Ячейка 23](#clover5-dev-cell23)).

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_37.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

3. Зафиксируйте винтами M3x8 ([Ячейка 8](#clover5-dev-cell8)) верхние дуги и перемычки в обратном порядке: должно получиться так, что перемычки направлены внутрь, а дуги наружу.

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_38.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

4. Установите и зафиксируйте запрессовочные гайки М3 ([Ячейка 1](#clover5-dev-cell1)) в отверстия по краям лучей.

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_39.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

5. Установите с нижней стороны защиту и зафиксируйте её на винты M3x10 ([Ячейка 13](#clover5-dev-cell13)).

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_40.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

6. С одной стороны большой ножки вкрутите винты M3x6 ([Ячейка 9](#clover5-dev-cell9)) во все отверстия, с другой стороны зафиксируйте их на алюминиевые стойки 10мм ([Ячейка 14](#clover5-dev-cell14)). В нижнем отверстии поверх стойки наденьте ножку (проставку) из TPU ([Ячейка 25](#clover5-dev-cell25)).

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_41.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

7. Разместите большую ножку на луче, как показано на изображении, и зафиксируйте винтами M3x6 ([Ячейка 9](#clover5-dev-cell9)). Выполните то же самое для остальных ножек.

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_42.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

8. Наклейте LED ленту на пластиковое кольцо (кольцо для крепежа LED ленты), после чего установите его в крючки на ножках и зафиксируйте провода пластиковым хомутом. Подключите питание во второй свободный UBEC, а сигнальный провод подключите в GPIO 9 (21 пин).

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_43.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

9. Установите пропеллеры в соответствии с классическим вращением, как представлено на изображении.

    ```{figure} @assets@/ru/assembly/clover5-dev/other_step_44.webp
    :alt: Установка защиты, ножек и LED ленты
    :width: 700px
    :align: center
    ```

```{caution}
Проверьте, что ни один из компонентов не остался незакрепленным. Перед первым включением убедитесь, что пропеллеры не задевают кожух и провода.
```
