## Сборка рамы

1. Совместите четыре луча между верхней и нижней декой рамы.

    ```{figure} @assets@/ru/assembly/clover5-dev/frame/frame_step_1.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    Установка лучей между верхней и нижней деками рамы
    ```
    
2. Установите винты M3x12 ([Ячейка 7](#clover5-dev-cell7)) в крайние отверстия лучей. Установите винты M3x40 ([Ячейка 6](#clover5-dev-cell6)) в центральные отверстия нижней деки.

    ```{figure} @assets@/ru/assembly/clover5-dev/frame/frame_step_2.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    Установка винтов в деку рамы
    ```

3. Установите запрессовочные гайки М3 ([Ячейка 1](#clover5-dev-cell1)) в предусмотренные отверстия нижней деки. Закрутите ранее установленные винты до надежной фиксации нижней деки и лучей рамы.

    ```{figure} @assets@/ru/assembly/clover5-dev/frame/frame_step_3.webp
    :alt: Сборка рамы
    :width: 700px
    :align: center
    Установка запрессовочных гаек в нижнюю деку рамы
    ```

## Установка бесколлекторных электродвигателей и регуляторов оборотов

1. Установите электродвигатели в предусмотренные отверстия лучей и закрепите их **винтами М3х8** ([Ячейка 8](#clover5-dev-cell8)).

    ```{figure} @assets@/ru/assembly/clover5-dev/motor_step_4.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    Крепление электродвигателей к лучам
    ```

    ```{caution}
    Убедитесь, что винты надежно закреплены и не выступают в область обмоток электродвигателей. Использование винтов неправильной длины может привести к повреждению обмоток и короткому замыканию.
    ```

2. Установите защиту проводов моторов на лучи.

    ```{figure} @assets@/ru/assembly/clover5-dev/motor_step_5.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    Установка защиты проводов моторов на лучи
    ```

```{caution}
Перед выполнением пайки убедитесь, что аккумуляторная батарея отключена от электрической системы конструктора.
```

```{caution}
Перед пайкой ознакомьтесь с правилами техники безопасности.
```

3. С верхней стороны контактов регулятора оборотов припаяйте силовые провода с конденсатором. Установите защитный колпачок на провода и припаяйте разъем XT60. С нижней стороны контактов регулятора оборотов припаяйте разъем XT30.

    ```{figure} @assets@/ru/assembly/clover5-dev/esc_step_6.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    Пайка силовых проводов
    ```

    ```{figure} @assets@/ru/assembly/clover5-dev/esc_step_7.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    Регулятор оборотов с припаянным конденсатором и разъемами в сборе
    ```

4. Установите регулятор оборотов (ESC). Припаяйте провода электродвигателей к регулятору оборотов, как показано на изображении ниже.

    ```{figure} @assets@/ru/assembly/clover5-dev/motor_step_8.webp
    :alt: Установка моторов и ESC
    :width: 700px
    :align: center
    Установка регулятора оборотов на раму 
    ```

## Установка одноплатного компьютера Raspberry Pi 5

1. Установите на пластиковую монтажную деку нейлоновые стойки M2.5 ([Ячейка 3](#clover5-dev-cell3)) с помощью винтов M2.5x4 ([Ячейка 17](#clover5-dev-cell17)).


    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_15.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Монтажная дека с установленными винтами
    ```

3. Установите Raspberry Pi 5 на установленные стойки M2.5х6 и зафиксируйте его винтами M2.5x4 ([Ячейка 17](#clover5-dev-cell17)).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_16.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Установка одноплатного компьютера Raspberry Pi 5
    ```

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_17.webp

    :width: 700px
    :align: center
    Raspberry Pi 5, установленный на монтажной деке
    ```

4. Снимите защитные пленки с обеих сторон термопрокладок. Установите термопрокладки на позиции, выделенные красными рамками на изображении. Установите радиатор охлаждения на Raspberry Pi 5. Для этого вставьте фиксирующие клипсы через радиатор в предусмотренные отверстия Raspberry Pi 5. Подключите систему охлаждения в предусмотренный разъем, расположенный под защитной крышкой.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_18.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Установка системы охлаждения на Raspberry Pi 5
    ```

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_19.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Raspberry Pi 5 с установленной системой охлаждения в сборе
    ```

5. Установите нейлоновые стойки M3x30 ([Ячейка 21](#clover5-dev-cell21)) на деку с Raspberry Pi 5 с помощью винтов M3x8 ([Ячейка 8](#clover5-dev-cell8)).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_20.webp
    :align: center
    Установка нейлоновых стоек на монтажную деку
    ```

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_21.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Монтажная дека с Raspberry Pi 5 и нейлоновыми стойками 
    ```

6. Установите собранную деку c Raspberry Pi 5 на антивибрационные стойки собранной рамы конструктора. Зафиксируйте деку винтами M3x4 ([Ячейка 10](#clover5-dev-cell10)).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_22.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Установка деки с Raspberry Pi 5 на антивибрационные стойки
    ```

7. Подключите к Raspberry Pi 5 шлейф телеметрии. Подключение выполните во внешнюю линию гребенки, начиная с пина 8 (GPIO 14). Черный провод подключите к пину 14 (Ground) (см. pinout). Ответную часть шлейфа подключите к порту UART4 полетного контроллера (черный провод — в крайний правый угол).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_23.webp

    :align: center

    ```
    
    ```{figure} @assets@/ru/assembly/clover5-dev/RPI_pinout.webp
    :alt: Установка Raspberry Pi
    :width: 400px
    :align: center
    ```

## Установка камеры, дальномера и экрана

4. Установите лазерный дальномер на деку захвата с помощью винтов M2x6 ([Ячейка 16](#clover5-dev-cell16)) и нейлоновых гаек M2 ([Ячейка 5](#clover5-dev-cell5)).

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_27.webp
    Установка лазерного дальномера
    ```

5. Подключите шлейф лазерного дальномера.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_28.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Подключение шлейфа лазерного дальномера
    ```

13. Установите деку захвата на раму конструктора с помощью винтов M3x8 ([Ячейка 8](#clover5-dev-cell8)). Подключите шлейф камеры к компьютеру согласно схеме подключения.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_29.webp
    :alt: Установка Raspberry Pi
    :width: 700px
    :align: center
    Установка монтажной деки на раму конструктора
    ```

6. Подключите шлейф дальномера к порту UART1 полетного контроллера (вставьте черный провод в крайний левый пин). Протяните кабель через отверстие в кожухе полетного контроллера.

    ```{figure} @assets@/ru/assembly/clover5-dev/RPI5_step_30.webp
    :alt: Установка Raspberry Pi
    ```

* Проверьте отсутствие поврежденных проводов и незакрепленных разъемов. 
* Убедитесь, что АКБ не имеет признаков повреждения, вздутия или перегрева.
