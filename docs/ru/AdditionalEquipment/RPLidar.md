**RPLidar C1** — это 2D-лидар, который сканирует окружающее пространство на 360°. Он измеряет расстояния до объектов в разных направлениях и формирует набор точек вокруг датчика. Эти данные можно использовать для обнаружения препятствий, навигации и построения карты окружающего пространства.

## Принцип работы

Лидар направляет инфракрасный лазерный сигнал на объект. Сигнал отражается от поверхности объекта и возвращается к датчику. Электроника лидара обрабатывает отраженный сигнал и вычисляет расстояние до объекта.

Одного измерения недостаточно, чтобы получить информацию обо всем пространстве вокруг квадрокоптера. Поэтому сканирующий модуль лидара вращается и выполняет множество измерений под разными углами. За один полный оборот лидар собирает набор точек. Для каждой точки известны направление измерения и расстояние до объекта.

Пример одного измерения:

```text
угол:      45°
расстояние: 1,8 м.
```

Если в направлении луча нет объекта или отраженный сигнал слишком слабый, лидар может не получить корректное измерение. Такие значения обычно игнорируются алгоритмами навигации и построения карты.

## Механическая система

Сканирующий модуль RPLidar C1 вращается по часовой стрелке. Обычная частота сканирования составляет 10 Гц. Это означает, что лидар выполняет примерно 10 полных оборотов в секунду и передает около 10 круговых сканов в секунду.

## Система координат лидара

Лидар описывает положение обнаруженных точек в полярной системе координат. Для каждой точки используются два значения:
*	Угол — направление, в котором лидар выполнил измерение.
*	Расстояние — дальность от лидара до обнаруженного объекта.

Начало координат находится в центре лидара. Ось `X` задает начальное направление отсчета углов. Угол определяет направление на измеренную точку относительно этой оси.

## Данные в ROS 2

В ROS 2 драйвер лидара обычно публикует данные в топик `/scan` в виде сообщений типа `sensor_msgs/msg/LaserScan`. Каждое сообщение содержит параметры одного сканирования и массив измеренных расстояний.

Основные поля `LaserScan`:

| Поле | Описание |
| --- | --- |
| `header.frame_id` | Имя системы координат лидара, например `laser`. |
| `angle_min`, `angle_max` | Начальный и конечный углы диапазона сканирования, в радианах. |
| `angle_increment` | Угловой шаг между соседними измерениями, в радианах. |
| `range_min`, `range_max` | Минимальная и максимальная допустимая дальность. |
| `ranges` | Массив измеренных расстояний, в метрах. |

Каждый элемент массива `ranges` соответствует отдельному направлению луча. Индекс `i` определяет угол измерения:

```text
angle = angle_min + i * angle_increment
distance = ranges[i]
```

## Использование

### Запуск через `clover2-settings`

Чтобы включить лидар на квадрокоптере, измените соответствующую настройку.

1. Запустите приложение командой `clover2-settings`.
2. Перейдите в раздел `additional_sensors` и включите параметр `2d_lidar`.

```{figure} @assets@/common/programming/sensors/rplidar/2d-lidar-enable.webp
:alt: Экран настроек 2d_lidar
:width: 90%
:align: center
```
<br>

3. Сохраните изменения. Перезапустите сервис clover2, чтобы применить настройки:
   
```bash
sudo systemctl restart clover2
```

После запуска сервиса лидар должен начать вращаться, а драйвер — публиковать данные в топик `/scan` с типом сообщения `sensor_msgs/msg/LaserScan`.

Откройте второй терминал и проверьте, появился ли топик:

```bash
ros2 topic list | grep scan
ros2 topic info /scan
```

В выводе команды `ros2 topic info /scan` проверьте тип сообщения. Он должен выглядеть так:

```text
Type: sensor_msgs/msg/LaserScan
```

Проверьте частоту публикации сообшений:

```bash
ros2 topic hz /scan
```

В режиме `Standard` ожидаемая частота сканирования составляет около 10 Гц. Фактическая частота может немного отличаться.

Чтобы посмотреть одно сообщение целиком, выполните команду:

```bash
ros2 topic echo --once /scan
```

Если нужно проверить только массив расстояний, выполните команду:

```bash
ros2 topic echo --once /scan --field ranges
```

Если топик `/scan` публикуется с ненулевой частотой, а поле `ranges` содержит измерения, драйвер передает данные. 

### Ручной запуск лидара

Если вы не используете автоматический запуск через `clover2-settings`, запустите драйвер лидара вручную. Откройте первый терминал и выполните команду:


```bash
ros2 run rplidar_ros rplidar_composition --ros-args \
  -p serial_port:=/dev/rplidar \
  -p serial_baudrate:=460800 \
  -p frame_id:=laser \
  -p inverted:=false \
  -p angle_compensate:=true \
  -p scan_mode:=Standard \
  -p topic_name:=scan
```

В этой команде параметры задают настройки драйвера:
*	serial_port — путь к последовательному устройству лидара;
*	serial_baudrate — скорость обмена данными;
*	frame_id — имя системы координат лидара;
*	inverted — настройка инверсии направления сканирования;
*	angle_compensate — включение компенсации угловых измерений;
*	scan_mode — режим сканирования;
*	topic_name — имя топика, в который драйвер публикует данные.

При успешном запуске в терминале может появиться сообщение следующего вида:

```text
RPLidar running on ROS2 package rplidar_ros. RPLIDAR SDK Version:2.1.0
RPLidar health status : OK.
current scan mode: Standard, sample rate: 5 Khz, max_distance: 16.0 m, scan frequency:10.0 Hz
```

Строка `RPLidar health status : OK.` означает, что драйвер сообщает о нормальном состоянии лидара. 
В последней строке указаны режим сканирования, частота измерений и максимальная дальность. 
Значения могут отличаться в зависимости от версии драйвера и настроек устройства.
