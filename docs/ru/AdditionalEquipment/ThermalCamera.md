# Тепловизионная камера

Вы можете подключить тепловизионную камеру к Raspberry Pi 5 на квадрокоптере и использовать полученные с нее данные для построения теплового изображения и определения температуры в отдельных точках кадра.

## Принцип работы

Тепловизионная камера улавливает инфракрасное излучение, которое испускают окружающие объекты. Датчик камеры преобразует это излучение в электрические сигналы. Электроника обрабатывает сигналы и формирует тепловое изображение, которое показывает распределение температуры на поверхности объектов.

Используемый тепловизионный модуль имеет разрешение 256x192 пикселя и передает два вида данных: обработанное тепловое изображение и матрицу температур.

## Данные в ROS2

Драйвер `clover2_thermal` обрабатывает данные камеры и публикует тепловое изображение и матрицу температур в отдельных топиках ROS 2. По умолчанию драйвер использует тип сообщения `sensor_msgs/msg/Image` для обоих топиков:

| Топик | Кодировка (`encoding`) | Содержимое |
| --- | --- | --- |
| `/thermal_camera/image_viz` | `mono8` | Обработанное тепловое изображение в оттенках серого. Каждый пиксель содержит значение яркости от 0 до 255. |
| `/thermal_camera/temperature` | `32FC1` | Матрица температур. Каждый пиксель содержит температуру в градусах Цельсия в виде 32-битного числа с плавающей точкой. |

Оба изображения имеют размер 256×192 пикселя. Координаты одного и того же пикселя совпадают в обоих топиках.

Используйте топик `image_viz`, чтобы просматривать тепловое изображение. Для измерения температуры обращайтесь к данным из  `temperature`.

```{hint}
Не определяйте температуру только по яркости пикселя: она не показывает точное значение температуры.
```

## Настройка

### Запуск через `clover2-settings`

Чтобы включить тепловизионную камеру на квадрокоптере, измените настройки с помощью `clover2-settings`.

1. Откройте терминал и запустите команду:

```bash
clover2-settings
```

2. Выберите группу `additional_sensors`.

```{figure} @assets@/common/programming/sensors/thermal-camera/clover2-settings.webp
:alt: Выбор группы additional_sensors в clover2-settings
:width: 700px
:align: center

Выбор группы additional_sensors в clover2-settings
```

<br>

3. В группе `additional_sensors` выберите настройку `thermal_camera`  и включите ее, установив значение `true`.

```{figure} @assets@/common/programming/sensors/thermal-camera/clover2-settings-thermal-camera.webp
:alt: Выбор настройки thermal_camera
:width: 700px
:align: center

Выбор пункта thermal_camera
```

<br>

4. Для сохранения изменений нажмите `ctrl+S`. Появится уведомление о сохранении.

```{figure} @assets@/common/programming/sensors/thermal-camera/clover2-settings-save.webp
:alt: Сохранение настройки тепловизионной камеры
:width: 700px
:align: center

Сохранение настройки тепловизионной камеры
```

<br>

5. Несколько раз нажмите `esc`, чтобы выйти из приложения.
6. Перезапустите сервис `clover2`, выполнив команду:

```bash
sudo systemctl restart clover2
```

После запуска сервиса драйвер тепловизионной камеры начнет публиковать кадры в топики `/thermal_camera/image_viz` и `/thermal_camera/temperature`.

## Использование

В Python матрицу температур удобно получать через клиент `Clover2`:

```python
from clover2 import Clover2

drone = Clover2()
temperature = drone.thermal_camera.get_temperature()

# Матрица NumPy имеет форму (192, 256), индексы задаются в порядке [y, x].
print(f"Температура в центре кадра: {temperature[96, 128]:.2f} °C")
```

Начало координат пикселей находится в левом верхнем углу изображения: координата `x` увеличивается слева направо, а координата `y` — сверху вниз. 

Метод `get_temperature()` возвращает последнюю полученную матрицу температур в формате NumPy. При первом обращении он ожидает данные до 5 секунд. Если камера не передаст данные за это время, метод вызовет исключение `TimeoutError`. 

Для получения исходного ROS-сообщения вместо матрицы NumPy используйте метод `drone.thermal_camera.get_temperature_msg()`.
