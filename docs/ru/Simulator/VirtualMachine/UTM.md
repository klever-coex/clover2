# Работа с UTM

[UTM](https://mac.getutm.app/) — это бесплатная Open Source программа для создания и запуска виртуальных машин на macOS. 
UTM поддерживает {abbr}`виртуализацию (запуск одной операционной системы внутри другой)` и {abbr}`эмуляцию (моделирование работы другой архитектуры процессора)`, работает на Mac с процессорами Intel и Apple Silicon и основана на технологии QEMU.

:::{warning}
Текущая инструкция и ARM64 образ виртуальной машины прeдназначены только для пользователей Mac с процессором Apple Silicon (ARM64, серия M).
:::

## Установка UTM

Скачайте UTM с официального сайта или из последнего стабильного релиза на GitHub [релиза на GitHub](https://github.com/utmapp/UTM/releases/latest/download/UTM.dmg). Установите стандартным способом: откройте `.dmg`, перенесите `UTM.app` в папку `Applications` (`Программы`) и запустите UTM.

Импорт существующего образа через мастер доступен начиная с UTM 4.7.

## Создание машины из QCOW2

Для Mac с Apple Silicon используйте образ Linux для **ARM64 / aarch64**.

1. Нажмите **File → New...** или кнопку **+**.
2. Выберите **Virtualize → Linux**.
3. На странице **Hardware** установите:
   - размер оперативной памяти - рекомендуется не менее 4 ГБ, но лучше 8 ГБ или больше, если позволяет компьютер;
   - число ядер процессора - рекомендуется не менее 2, но лучше 4 или больше, если позволяет компьютер;
   - чекбокс **Enable hardware OpenGL acceleration**, чтобы ускорить отрисовку графики в симуляторе.

   ```{image} @assets@/common/simulator/utm/hardware.webp
   :alt: Симулятор Gazebo
   :width: 100%
   ```
4. На странице Linux:
   - оставьте **Use Apple Virtualization** выключенным;
   - в разделе **Boot Image Type** выберите **Import existing drive**, нажмите **Browse…** и укажите файл `.qcow2`.
6. Нажимайте **Continue**. Общую папку можно пока не задавать.
7. На странице **Summary** укажите имя машины и нажмите **Save**. Дождитесь завершения импорта диска.
8. Выберите созданную машину и нажмите **▶**. Войдите в Linux с учётными данными из описания образа.

Если вместо Linux открывается **UEFI Shell** или появляется сообщение об отсутствии загрузочного устройства, остановите машину и проверьте наличие импортированного диска в **Edit → Drives**. Убедитесь, что образ предназначен для ARM64 и загрузки через UEFI, а в разделе **QEMU** включён **UEFI Boot**.
