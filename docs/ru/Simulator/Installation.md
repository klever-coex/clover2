Для работы с симулятором необходимо подготовить программную среду. Один из вариантов — запустить Linux в виртуальной машине внутри другой операционной системы, например Windows или macOS. Виртуальная машина позволяет использовать Linux без отдельной установки этой операционной системы на компьютер.

```{important}
Для компьютеров с ОС Linux можно использовать VMware Workstation Pro и `.ova` образ, однако этот вариант не тестировался. Поэтому для Linux рекомендуется использовать [Dev Container](./Installation/DevContainer).
```

## Выбор способа установки

Выберите вариант установки в зависимости от операционной системы и процессора вашего компьютера.

* **Linux**: используйте [Dev Container](./Installation/DevContainer). Это изолированная среда разработки, которая работает в Docker и позволяет запускать необходимые инструменты без установки отдельной виртуальной машины.
* **Windows** с процессором Intel или AMD (x86_64): используйте [VMware Workstation Pro](./Installation/VmWare) и готовый образ в формате OVA.
* **Mac** с процессором Apple Silicon (ARM64, серия M): используйте [UTM](./Installation/UTM) и готовый образ в формате QCOW2.

```{hint}
Если вы не знаете, какой процессор установлен в вашем компьютере, проверьте его модель в настройках системы.
```

## Скачивание образа

Скачайте готовый образ симулятора с [klever-doc.tech](https://klever-doc.tech/), соответствующий выбранному способу запуска.

Проверьте формат файла перед скачиванием:
*	для **VMware Workstation Pro** нужен образ в формате `.ova`;
*	для **UTM** нужен образ в формате `.qcow2`;
*	для **Dev Container** следуйте инструкции по настройке среды: отдельный образ виртуальной машины может не потребоваться.

После подготовки среды перейдите к разделу {doc}`Использование <Usage>`, где приведены общие команды для сборки и запуска симулятора.
