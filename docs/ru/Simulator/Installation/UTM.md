# UTM

[UTM](https://mac.getutm.app/) — бесплатная программа с открытым исходным кодом для создания и запуска виртуальных машин на macOS. 

UTM поддерживает два режима работы:
* **Виртуализация** (запуск одной операционной системы внутри другой) позволяет запускать гостевую операционную систему на том же типе процессора, который установлен в компьютере.
* **Эмуляция** (моделирование работы другой архитектуры процессора) позволяет запускать операционные системы, рассчитанные на другой тип процессора.

UTM основана на технологии QEMU и работает на компьютерах Mac с процессорами Intel и Apple Silicon.

:::{attention}
Эта инструкция и образ виртуальной машины ARM64 предназначены только для компьютеров Mac с процессором Apple Silicon (серия M).
:::

## Установка UTM

Скачайте UTM с официального сайта или загрузите последнюю [стабильную версию на GitHub](https://github.com/utmapp/UTM/releases/latest/download/UTM.dmg). 

Чтобы установить программу, откройте загруженный файл `.dmg`, перенесите `UTM.app` в папку `Applications` (`Программы`) и запустите UTM.

Импорт существующего образа через мастер доступен начиная с UTM 4.7.

## Создание машины из QCOW2

Для компьютеров Mac с процессорами Apple Silicon используйте образ Linux для архитектуры **ARM64 / aarch64**.

1. Нажмите `File` → `New...` или кнопку `+`, чтобы создать виртуальную машину.
2. Выберите `Virtualize` → `Linux`.
3. На странице `Hardware` задайте параметры виртуальной машины:
   - Размер оперативной памяти. Рекомендуется выделить не менее 4 ГБ. Если компьютер позволяет, выделите 8 ГБ или больше.
   - Ядра процессора. Рекомендуется выделить не менее 2 ядер. Если компьютер позволяет, выберите 4 ядра или больше.
   - Установите флажок `Enable hardware OpenGL acceleration`, чтобы ускорить обработку графики в симуляторе.

   ```{image} @assets@/common/simulator/utm/hardware.webp
   :alt: Симулятор Gazebo
   :width: 100%
   ```
4. На странице Linux выполните следующие настройки:
   - оставьте параметр `Use Apple Virtualization` выключенным.
   - в разделе `Boot Image Type` выберите `Import existing drive`.
   - Нажмите `Browse…` и выберите файл образа с расширением `.qcow2`.
5. Нажимайте `Continue`, чтобы перейти к следующему шагу. Общую папку пока настраивать не нужно.
6. На странице `Summary` укажите имя виртуальной машины и нажмите `Save`. Дождитесь завершения импорта диска.
7. Выберите созданную машину и нажмите `▶`, чтобы запустить ее. Дождитесь загрузки Linux и войдите в систему, используя учетные данные из описания образа.

Если вместо Linux открывается **UEFI Shell** или появляется сообщение об отсутствии загрузочного устройства, остановите виртуальную машину и проверьте настройки:
* Откройте `Edit` → `Drives` и убедитесь, что образ `.qcow2` подключен как диск.
* Убедитесь, что образ предназначен для архитектуры ARM64 и поддерживает загрузки через UEFI.
* В разделе `QEMU` включен `UEFI Boot`.

После входа в Linux перейдите к {ref}`общей инструкции запуска симулятора <simulator-launch>`.
