Перед первым запуском конструктора квадрокоптера настройте полетный контроллер и бортовой компьютер Raspberry Pi.

## Настройка полетного контроллера

Для настройки {doc}`полетного контроллера <Setup/QGC>` используйте программу QGroundControl. Установите прошивку, откалибруйте датчики, настройте аппаратуру управления, полетные режимы и параметры питания.

## Настройка Raspberry Pi

Запишите образ на карту памяти для {doc}`Raspberry Pi <Setup/RPi>`. Подключитесь к Rasbperry Pi через Web IDE или SSH. Подготовьте карту ArUco-маркеров и настройте камеру, навигацию и другие компоненты с помощью `clover2-settings`.
