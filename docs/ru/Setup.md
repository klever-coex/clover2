Перед использованием конструктора квадрокоптера настройте полетный контроллер и Raspberry Pi.

Для настройки {doc}`полетного контроллера <Setup/QGC>` используйте QGroundControl. Загрузите прошивку, выполните калибровку датчиков, настройте аппаратуру управления, полетные режимы и питание.

Запишите образ на карту памяти {doc}`Raspberry Pi <Setup/RPi>`. Подключитесь к квадрокоптеру через Web IDE или SSH, подготовьте карту маркеров и настройте другие компоненты с помощью `clover2-settings`.
