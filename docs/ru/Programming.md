Фреймворк `clover2` построен на `ROS 2` — открытой и широко распространенной платформе для разработки робототехнических систем. Это позволяет создавать собственную логику автономного полета на языках программирования, который поддерживает `ROS 2`. 

Самый простой способ начать разработку — использовать готовую Python-обертку `clover2`, которая содержит весь необходимый функционал для решения прикладных задач. Она работает поверх ROS 2 и взаимодействует с конструктором через те же топики и сервисы, которые доступны другим узлам системы.

Если вам нужна максимальная производительность или нестандартная логика, создавайте собственные узлы напрямую на ROS 2. Для этого можно использовать Python (rclpy), C++ (rclcpp) и другие поддерживаемые языки. Узлы могут обмениваться данными с остальными компонентами системы через топики и сервисы.
