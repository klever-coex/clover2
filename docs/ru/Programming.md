Фреймворк `clover2` построен на `ROS 2` — открытой и широко распространённой робототехнической платформе. Это позволяет писать собственную логику автономного полёта на любом языке программирования, который поддерживается самим `ROS 2`. 

Самый простой способ начать — готовая Python-обёртка `clover2`, которая уже содержит весь необходимый функционал для решения прикладных задач. Под капотом она использует ROS 2 и обращается к дрону через те же топики и сервисы, что доступны любой другой ноде.

Если нужна максимальная производительность или нестандартная логика, можно писать собственные узлы напрямую на ROS 2 — на Python (rclpy), C++ (rclcpp) или других языках и общаться с остальной системой через топики и сервисы.
