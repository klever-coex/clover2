# clover2_bringup

Пакет содержит все launch-файлы, необходимые для запуска проекта, а также кастомные actions для автоматизации конфигурации.

## Группа запуска сенсоров (sensing)

Для стандартизации способа запуска драйверы устройств вынесены в отдельные файлы в папке `launch/sensing`. Поэтому launch-файлы имеют некотрые обязательные аргументы.

### Шаблон аргументов запуска драйвера камеры

| Аргумент       | Обязательный | По умолчанию         | Описание                                                                                                  |
| -------------- | ------------ | -------------------- | --------------------------------------------------------------------------------------------------------- |
| camera_id      | Да           |                      | Идентификатор камеры (числовой для libcamera или путь dts)                                                |
| camera_name    | Нет          | camera               | Имя ноды камеры                                                                                           |
| container_name | Нет          | camera_container     | Имя ROS2 контейнера для загрузки драйвера камеры как компонента                                            |
| frame_id       | Нет          | $(camera_name)\_link | Идентификатор TF2 vision frame                                                                            |
| ns             | Нет          | -                    | ROS2 namespace камеры                                                                                     |
| param_file     | Нет          | params/klever5.yaml  | Путь к файлу дополнительных параметров                                                                    |
| use_composition| Нет          | false                | Если true — драйвер камеры загружается как компонент в контейнер $(container_name). Иначе как отдельная нода |

### Шаблон аршументов запуска 2D лидара

| Аргумент   | Обязательный | По умолчанию             | Описание                                   |
| ---------- | ------------ | ------------------------ | ------------------------------------------ |
| lidar_id   | Нет          | /dev/rplidar0            | Путь к последовательному устройству лидара |
| lidar_name | Нет          | lidar                    | Имя ноды лидара                            |
| ns         | Нет          | -                        | ROS2 namespace лидара                      |
| param_file | Нет          | params/klever5.yaml      | Путь к файлу дополнительных параметров     |

### Подмена пакета сенсоров

Главный launch-файл `klever5.launch.xml` принимает аргумент `sensing_pkg`, который определяет пакет, из которого загружаются launch-файлы сенсоров.
Это позволяет подменить стандартные драйверы 2D лидара и камеры на пользовательские без изменения оригинального пакета.

| Аргумент    | Обязательный | По умолчанию     | Описание                                                        |
| ----------- | ------------ | ---------------- | --------------------------------------------------------------- |
| sensing_pkg | Нет          | clover2_bringup  | Имя пакета, предоставляющего файлы `launch/sensing/*.launch.xml` |

Пример использования — запуск klever5 с пользовательским пакетом сенсоров:

```
ros2 launch clover2_bringup klever5.launch.xml sensing_pkg:=my_custom_sensing
```

Подставляемый пакет должен предоставлять те же пути к launch-файлам (например, `launch/sensing/2d_lidar.launch.xml`, `launch/sensing/camera.launch.xml`).
